## grep

filtert die Zeile nach der du suchst und nur diese wird dir dann als output wiedergeben!

Bsp: `$ grep Leonie klassenkassa.csv`<br>
 **Hiermit suchen wir nach Leonie in der Datei klassenkassa.csv**

Output:
```
Leonie,06.11.2023,20.0,Kopierkosten
Leonie,04.10.2023,25.0,Werkstatt
```

## Pipes

Eine Pipe `|` leitet die Ausgabe eines Befehls direkt als Eingabe an den nächsten Befehl weiter.

Bsp.: `$ cat klassenkassa.csv | grep Leonie` <br>

- **`cat` liest die gesamte Datei aus.**
- **Die Pipe `|` schnappt sich diesen Text**.
- **`grep` bekommt diesen Text filtert ihn nach „Leonie“.**

Output:
```
Leonie,06.11.2023,20.0,Kopierkosten
Leonie,04.10.2023,25.0,Werkstatt
```

---

## tr

`tr` tauscht Zeichen aus oder löscht sie gezielt.

Bsp.: `$ echo "hallo kevin" | tr 'a-z' 'A-Z'` <br>

- **hallo kevin wird wegen dem `echo` ausgegeben.**
- **wegen dem Pipe `|` wird die Ausgabe des echos als Eingabe weitergegeben für `tr`.**
- **`tr 'a-z' 'A-Z'` sorgt dafür, dass alle kleinbuchstaben von a bis z zu großbuchstaben A bis Z werden (ersetzt).**

Output:
```
HALLO KEVIN
```

## shuf

`shuf` bringt die Zeilen eines Textes oder einer Datei in eine zufällige Reihenfolge.

Bsp.: `$ shuf klassenkassa.csv` <br>

**Die Reihenfolge der Zeilen in der Datei klassenkassa.csv sind hiermit komplett zufällig und gemischt** <br>
**WICHTIG: Die Reihenfolge bleibt nie gleich, sondern bei jeder Ausführung verschieden**

Output:  **(ohne shuf)**
```
Maximilian,21.09.2023,3.0,Bus
Sophia,22.09.2023,15.0,Werkstatt
Jonas,21.09.2023,3.0,Bus
Lena,18.09.2023,13.0,Werkstatt
Lukas,15.09.2023,2.5,Kino
...
```


Output:  **(mit shuf)**
```
Elias,04.10.2024,8.21,Bus
Luca,17.09.2024,14.89,Werkstatt
Emma,26.10.2023,10.3,Walter
```
